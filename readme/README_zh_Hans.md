# JANCTION Render（Dify 插件）

在 Dify 的智能体和工作流里，用云端 GPU 渲染 Blender 场景和 3D 模型。发送 `.blend` 文件、Blender Python（bpy）脚本或 3D 文件（GLB / glTF、FBX、USD、OBJ、STL、PLY、Alembic），几秒内得到预览图，并附带问题点评和 bpy 修复代码；确认后在 NVIDIA GPU 上渲染最终帧或 MP4。无需本地 GPU 和 Blender。

- 开发者：JasmyLab Inc.（[JANCTION Render](https://render.janction.jp/zh?src=dify) 的运营方）
- 联系方式：contact@jasmylab.com
- 源代码：https://github.com/freeman745/janction-render-dify

## 设置

1. 在 Dify 插件市场安装本插件。
2. 在 Dify 中打开 **工具 → JANCTION Render → 授权** 并保存。API 密钥是选填的：
   - **留空**（推荐先这样用）：第一次使用时，插件会自动为这个工作空间领取免费密钥（无需注册、无需绑卡，附带免费 GPU 时间），并保存在插件存储里。
   - **填写密钥**（`jr_...`）：使用自己已有的密钥，比如已经充值的密钥。手动获取：`curl -X POST https://render.janction.jp/v1/keys`。

插件需要能通过 HTTPS 访问 `render.janction.jp`。交给工具的场景文件会从 Dify 读取后发送到服务（每个文件最大 100 MB；更大的场景请放在 https 链接上，用 `scene_url` 传入）。

## 工具

| 工具 | 作用 | GPU 时间 |
|---|---|---|
| 渲染预览 | 几秒内渲染 1~4 帧，返回图片和点评（结论、问题、bpy 修复代码） | 每天 2 GPU 分钟以内免费 |
| 估算渲染 | 正式渲染前估算 GPU 时间、等待时间和价格 | 不消耗 |
| 正式渲染 | 最终帧或视频（PNG、EXR、MP4、WebM、ProRes、GIF、WebP）；`max_yen` 是费用上限（0 = 只用免费时间），由应用搭建者在工具设置里设定，模型不能修改 | 消耗 |
| 渲染状态 | 查看任务状态，完成后返回图片 / 视频链接 | 不消耗 |
| 下载结果 | 把结果图片和视频作为 Dify 文件返回 | 不消耗 |
| 取消渲染 | 取消排队中或运行中的任务 | 不消耗 |
| 场景信息 | 不渲染，读取相机、帧范围、分辨率和缺失的文件 | 不消耗 |
| 最近的任务 | 这个密钥最近的任务和仍保留的场景 | 不消耗 |
| 搜索 3D 素材 | 搜索 Poly Haven 的免费 CC0 模型、贴图和 HDRI，供场景脚本使用 | 不消耗 |
| 分享 / 取消分享 | 把已完成的渲染发布成公开页面，或撤下 | 不消耗 |
| 余额和用量 | 剩余免费时间、余额和充值方式 | 不消耗 |
| 服务状态 | GPU 是否在线、预计等待时间 | 不消耗 |

场景用以下任意一种方式指定：`scene_file`（文件）、`scene_id`（之前任务的场景，不用重新发送）、`scene_url`（https 链接）或 `scene_script`（搭建场景的 bpy 代码）。

## 用法

在 **Agent** 应用中添加 JANCTION Render 的工具，然后这样提问：

- "用这个 .blend 文件渲染一张预览图，看看光线有没有问题。"
- "把这个 GLB 模型做成 360 度转台展示视频（MP4）。"
- "写一个 bpy 脚本，搭一个木桌上放着咖啡杯的场景，然后渲染出来。"

工具说明会引导模型先预览、再估算，正式渲染前先征求用户同意。

在 **工作流** 中，常见的顺序是：渲染预览 →（查看点评）→ 估算渲染 → 正式渲染（`wait_seconds` 设为 0）→ 循环调用渲染状态直到 `status` 为 `done` → 下载结果。一次工具调用最多等待 200 秒；更长的渲染会继续运行，用"渲染状态"取回结果。

## 价格

每个新密钥赠送 100 日元 GPU 时间；保存银行卡（不扣款）再赠送 400 日元。预览每天 2 GPU 分钟以内免费；免费时间用完后，按每 GPU 秒 0.1 日元从预付余额扣除。正式渲染的费用不会超过 `max_yen`，默认值 0 表示只在免费时间够用时才渲染。最新价格：https://render.janction.jp/zh/pricing

见 [PRIVACY.md](../PRIVACY.md)。场景和结果在最后一次使用 24 小时后由服务删除。充值和绑卡都在浏览器中通过工具返回的链接完成（"余额和用量"工具，或因余额不足被拒的渲染）；插件不接触任何支付信息。
